# RSEC — Portafolio multimedia

Portafolio personal de fotografía, edición de video, diseño gráfico y producción audiovisual.

## Tecnologías
- HTML5
- CSS3
- Reproductores de video HTML5
- Sin JavaScript

## Organización
- `index.html`: página principal
- `estilos.css`: estilos y diseño adaptable
- `img/`: fotografías, portadas y logo
- `video/`: 5 videos en formato MP4
- `documentos/`: proyectos y manuales en PDF/SVG

## Publicación
Para usar GitHub Pages, abrir **Settings > Pages** y seleccionar **Deploy from a branch**, rama **main**, carpeta **/(root)**. Después de cargar los archivos multimedia, el sitio estará disponible en la dirección que GitHub indique.

**Nota:** la página requiere que las carpetas `img`, `video` y `documentos` estén subidas para mostrar todos los proyectos.
